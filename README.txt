DANI-PORTFOLIO — QUICK SETUP

1. Open this folder in Visual Studio Code.
2. In the assets folder, copy your photo and name it exactly:
   DSC01067mm.JPG.jpeg
   (The HTML is already configured to use that filename.)
3. Copy your resume PDF into assets and name it exactly:
   Dani_Rajan_Jacob_Resume.pdf
4. Open index.html with Live Server when you want to preview the site.

BEFORE PUBLISHING:
- In index.html, replace YOUR_EMAIL@gmail.com with your email address.
- Replace YOUR_GITHUB_URL with your GitHub profile URL.
- Add your actual photo and resume PDF to the assets folder.

The site uses HTML and CSS only. No JavaScript or framework is required.
